# VibeBoard

A small, polished moodboard generator: describe a vibe and get a color palette, image prompts, music inspiration, and mood tags. Save boards in your browser and revisit them later.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Notes

The MVP generates boards locally in the browser, so no API keys or backend are required. Saved boards use browser local storage.
